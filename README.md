# Livin Up

Livin Up is a polished, luxury-style static marketing website for a creative brand studio focused on hospitality, culture, retail, and community-led experiences.

The project is built as a multi-page front-end experience with editorial typography, layered glassmorphism interfaces, and premium case-study storytelling.

## Project structure

- [index.html](index.html) — home page
- [work.html](work.html) — featured portfolio and case-study modal
- [services.html](services.html) — service offering overview
- [gallery.html](gallery.html) — visual gallery with lightbox
- [studio.html](studio.html) — studio story and brand positioning
- [contact.html](contact.html) — contact and inquiry form
- [styles.css](styles.css) — shared design system and page styling
- [script.js](script.js) — site interactions, modal logic, carousels, and lightbox behavior
- [img/](img/) — brand and supporting visual assets

## Features

- Premium editorial aesthetic with luxury brand styling
- Responsive multi-page layout
- Mobile navigation and desktop header treatment
- Service and portfolio carousels
- Case-study modal with image slide navigation
- Glass-style gallery viewer
- Consistent footer and contact details across pages

## Notes

This project is intentionally built as a static front-end prototype, making it easy to customize copy, colors, layouts, and brand assets without a framework or build pipeline.

If you want to adapt the design for a real client, the easiest next improvements would be:

- replace placeholder imagery with approved photography
- replace generic contact information with live details
- add real content blocks and CMS-ready copy
- wire the contact form to an email or backend service

## Design direction

The visual language blends:

- warm luxury neutrals
- deep navy and burgundy accents
- high-contrast serif headlines
- glassmorphism surfaces and soft blur effects

This creates a cinematic, premium look suitable for lifestyle and culture-first brands.
